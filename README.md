# StegaNSS

A web-based multimedia steganography application for securely hiding and extracting confidential data within image, audio, and video files.

## 🚀 Features

- 🔐 Hide confidential data inside multimedia files
- 🔎 Extract hidden data from steganographic files
- 🖼️ Image steganography
- 🎵 Audio steganography
- 🎥 Video steganography
- 🔒 Encryption and decryption support
- 👤 User registration and login
- 📊 User dashboard
- 🛡️ Metadata handling and secure processing

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- OpenCV
- Cryptography
- Multimedia processing
